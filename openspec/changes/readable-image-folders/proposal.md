# 面向本地浏览的图片目录

用户要求并最终确定：保存根/公众号名/文章标题/图片，不加日期层或开关。作者无真实独立信息时直接使用公众号名。既有5篇49图也获明确整理授权。

## Contract
- 内部文章/账号ID、归并身份和公共图片URL不变。物理相对路径改为可读目录，保留原序号/短内容指纹文件名即可。
- 新下载、补图和导入使用同一存储入口；旧UUID/library相对路径和已登记多个图片根持续可读。
- 名称清洗Windows非法字符、保留设备名、尾部点空格和控制字符，并约束路径长度。不同账号或同名文章不能共享归属；必要时加稳定短ID消歧，日常目录不显示长UUID。补图复用已分配目录，名称改变不自动搬移资产。
- 复用现有PUT /api/settings中的migrateExisting=true显式迁移，同一根也能整理；false不移动旧图片。先复制并核验全部源/目标，再事务更新根/资产路径和映射，成功后只清理已登记、未变化、非其他目标的原件。目录或文件冲突拒绝，不覆盖陌生文件。
- 保留既有资产根限制、每级目录链接检查、32MiB校验、来源/目标指纹、互斥及关闭等待，不能通过放宽路径深度开放任意路径。
- 不递归删除用户目录。清空UUID目录仅在位于预期根且非链接且为空时执行单个rmdir；未知文件保持。

## Acceptance
用隔离数据覆盖正常名、长名、非法字符、设备名、同名账号/标题、重复保存/重启/改名、旧格式兼容、安全路径、事务失败和迁移源目标交叉保护。生产整理核实49图片SHA256及公共资源字节、467文章和5篇完整保持，原目录若含未知内容保留并报告。
