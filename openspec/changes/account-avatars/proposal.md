# 公众号真实头像

用户明确要求公众号卡片使用真实头像。沿用现有公众号/文章解析、微信图床校验和本地预览缓存，不以文章封面替代头像，不增加第三方依赖或新的采集通道。

## Contract
- Account增加可选清洗后的avatarSource与本地avatarUrl；ParsedArticle增加可选头像字段，缺失字段的旧记录继续可用。
- GET /api/accounts/:id/avatar只访问该账号已登记来源，使用现有CoverCache的account:命名空间，不接受任意URL或文件路径，不获取正文资料兜底。
- POST /api/accounts/:id/profile是明确资料刷新，只读取该号一篇既有文章，核对biz后更新头像；保留正文、assets、jobs、归档计数和其他账号偏好。网络返回后基于最新账号合并，避免覆盖并发策略修改。
- 图片沿用既有HTTPS/图床域名白名单、敏感参数清洗、尺寸/类型/完整性验证、来源阻断及缓存去重/冷却。头像与封面一样不计正文图片，不随正文迁移。
- 列表轮询不触发资料抓取；卡片头像明确点击可刷新。头像缺失或加载失败显示中性占位，取不到头像不改变原资料。

## Acceptance
隔离测试覆盖解析、资料单次读取、来源越界/跨号/受阻/缺失、缓存重启、原计数/正文不变及并发偏好保留。浏览器验证头像真实解码、失败占位和明确刷新。生产验证只为用户指定号补齐一次头像，核实原49张正文图片校验和及467条记录保持。
