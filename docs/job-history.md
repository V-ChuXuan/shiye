# 任务历史按需读取

## 1. 范围与触发

任务中心保留进行中、待处理和已完成三分区。仅已完成历史分页，不删除或归档数据库记录；非completed任务不截断。旧GET/jobs与内部采集调度仍保持既有完整列表语义，无schema或依赖变更。

## 2. 签名

- `GET /api/jobs` → `Job[]`，旧行为。
- `GET /api/jobs?scope=open` → 全部非completed的公开`Job[]`。
- `GET /api/jobs/history?page=1&pageSize=20&focus=<id可选>` → `JobPage {items: Job[],total:number,page:number,pageSize:number}`。
- `GET /api/summary`增加`completedJobsCount:number`；其他字段不变。

## 3. 契约

历史仅completed，以SQLite rowid降序稳定排序，在SQL内筛选、计数及LIMIT/OFFSET；不在应用中读完再切片。返回公开Job，不暴露内部分页预算、文章ID清单或发现断点。默认20条、最多100条。focus对应已完成任务时返回它所在页；未知或未完成ID不错误定位其他记录，按普通请求页处理。

前端常规4秒轮询只读取open任务、账号和summary。进入任务页、翻页、手动刷新或completedJobsCount变化时刷新历史；首次获知计数也对齐一次，防止首次历史与汇总之间完成的任务被遗漏。进度变化本身不加载历史。计数信号覆盖两轮之间创建并完成的短任务。历史页数与选定页不持久化，不影响文章跨页选择；页面错误独立反馈并可重试，保留旧内容。路由定位完成历史只在需要时确定页并展开，不被轮询反复抢焦点；用户仍可翻到其他页。同页切换定位时保留已有行直到响应替换，避免先聚焦再卸载导致焦点丢失。

## 4. 校验与错误矩阵

| 输入或时序 | 结果 |
|---|---|
| scope省略/open | 分别旧全列表/未完成列表 |
| 未知scope或参数、重复/非字符串参数 | 400，不改变任务 |
| page/pageSize非正安全整数或size>100 | 400，无截断伪成功 |
| focus非法类型或长度>128 | 400 |
| 已完成focus在后页 | 按同一排序定位所在页 |
| 未知/未完成focus | 普通页，不展开错误任务 |
| 慢旧响应晚于翻页/离开页面 | 忽略，不覆盖新页 |
| 两次轮询间新增并完成任务 | count变化触发当前历史页刷新 |
| 历史读取失败 | 保留旧页与可见重试，未完成任务照常显示 |

## 5. 用例

基本为空任务中心与20条以内历史；正常为5000条完成历史夹杂全部未完成任务，逐页查看或通过深链进入旧任务。异常用例包括参数错误、旧请求乱序、历史接口失败，以及任务在两次轮询之间完整执行。

## 6. 验收

离线API测试断言5000条总数/页长、SQL筛选分页、排序、focus、未知参数、public字段及旧数组兼容；summary精确completed计数。浏览器验证翻页/范围、跨页深链展开/焦点、键盘和窄屏、乱序/失败重试、非任务页不读历史、4秒轮询不全取历史和短任务计数更新。样本数据是隔离构造，不当作真实长期使用性能保证。

## 7. 错误与正确

错误：每4秒取全量历史再在前端slice；或只观察open任务变化，漏掉轮询间完成的任务。正确：SQL分页历史，轻量计数识别变化；非completed保留完整操作和恢复上下文。
