# 本地归档契约

可复跑的隔离容量、慢操作和进程中断验证见[可靠性演练](reliability-drills.md)，结果有明确样本与模拟边界。

识别请求关闭、文库取消和阅读重试的可观察边界见[safe-cancel-reader.md](safe-cancel-reader.md)。

阅读检索、内部任务窄SQL及0.1.1界面恢复的跨层规则见[library-polish.md](library-polish.md)。旧jobs与归档数据契约保持。

## 1. 范围与触发

跨端 API、SQLite 任务状态、Windows会话与归档文件共同组成软件闭环。正式契约以 shared/types.ts 和 server/app.ts 为准，本文记录必须保持的边界。

## 2. 签名

GET /api/summary、/api/accounts、/api/articles、/api/articles/:id、/api/jobs。
POST /api/accounts {url}；PATCH /api/accounts/:id {updatePolicy,intervalMinutes}。
POST /api/accounts/:id/connect {}；POST /api/accounts/:id/discover {maxPages}。
GET /api/articles/page {page?,pageSize?,accountId?,q?,status?,since?,until?} -> {items,total,page,pageSize}；原/api/articles数组接口保持兼容。
发现请求同时支持maxArticles?:number；新UI提交maxArticles与maxPages，主篇数预算默认100，批次默认20。
POST /api/jobs {accountId,articleIds}；POST /api/jobs/:id/pause、/resume。
POST /api/import {path,limit}；GET /api/assets/:articleId/:seq。
GET /api/covers/:articleId：仅取得服务器已记录的文章来源封面，不接受代理URL或文件路径参数。
GET /api/settings：当前及默认正文图片目录、data目录和目录选择能力。
PUT /api/settings {imageDirectory,migrateExisting?}：校验保存位置；migrateExisting省略或false时不迁移，只有true迁移。成功返回settings、migratedImages和warnings；非boolean迁移选项返回400。
POST /api/settings/choose-directory：返回用户选择的path或null，取消不保存设置。
GET /api/about：拾页名称、真实package版本和用途说明。
UI hash：#accounts?accountId=A&fromJob=J 为任务重连上下文；#jobs?id=J 为任务定位。仅作为当前模型实体ID匹配，不增加后端接口。
文章行「下载/补全」直接POST /api/jobs {accountId:该行accountId,articleIds:[该行id]}，成功后进入#jobs?id=返回id；与顶部批量确认分离。「查看图集」使用既有readerMode=gallery并打开#reader?id=该行id，不发采集请求。
GET /api/accounts/:id/avatar：仅读取该账号已登记的头像来源，复用本地预览缓存；不接受URL参数，不获取文章资料兜底。
POST /api/accounts/:id/profile：明确读取该公众号一篇既有文章取得头像，验证biz后只更新账号头像资料；不采集/改写正文、资产或任务。

## 3. 请求、响应与存储

成功返回直接实体/数组；错误返回安全的 {error,code?}。任务 progress 是0至100百分比。
PORT 默认4387，WECHAT_ARCHIVE_DATA默认data。服务只绑定127.0.0.1；静态前端和API同源。
accounts、articles、aliases、assets、jobs、job_items持久化；会话不入库。公开sn/chksm是文章请求参数，uin/key/pass_ticket等是短期会话参数，不能混入归档URL。
发现条目的可选coverUrl保存为清洗后的coverSource；公共文章coverUrl始终为本地资源，优先正文已保存图片，否则使用本地封面接口。封面缓存在data/covers，不加入assets/blocks，不改变status、imageCount或savedImageCount；首次可见时读取，已缓存内容无需微信会话。现有旧记录无需DDL迁移。
来源封面保留清单尺寸，响应流上限2MiB；缓存按内部文章ID和清洗后的来源URL摘要分键，下载串行且同键请求去重。失败至少冷却60秒；读取成功缓存优先于共享来源门，未缓存图片受既有验证/认证/限流规则约束。
公众号头像来自文章中的公众号头像字段，沿用既有微信图床白名单和HTTPS/敏感参数清洗；Account的可选avatarSource保存来源，avatarUrl为本地资源地址。头像缓存复用CoverCache，以账号命名空间与清洗来源分键，不加入正文assets，不增加正文图片计数，也不随正文图片迁移。资料刷新限于明确操作，缺失/跨公众号/受阻时保留原头像与原文库；列表轮询和头像GET不能触发正文资料读取。
头像avatarUrl可附带来源摘要版本查询，以刷新文档内图片资源；该查询不作为远程来源，GET只使用数据库已登记的头像来源。
正文图片物理目录固定为保存根/公众号名/文章标题/图片，不提供日期层开关，不把日期拼入目录前缀。内部ID及公共资源URL不变，名称必须经Windows文件名清洗和长度限制，同名归属必要时以稳定短ID消歧。补图复用已分配目录，改标题或账号名不隐式移动旧图。兼容旧UUID及library路径；显式migrateExisting=true可在同一根下整理为新结构，事务登记新相对路径后再清理已核验旧源，不能删除本轮其他目标或未知文件。
正文图片根设置持久化到既有runtime表；正常生产默认项目pictures，隔离数据实例的默认目录落在自身数据区域。未配置旧库识别data/library登记图片，旧file的library前缀保持可读兼容。内部StoredAsset.storageDirectory记录该图片所在根，公共Asset响应剥离此字段。默认切换位置只事务记录旧图根并提交新默认根，不复制、移动或删除旧图，也不要求读取旧图；新下载和导入写入当前根。原有/api/assets资源URL不变，不允许客户端请求任意路径。
显式迁移先从各资产登记根校验并复制到目标、再次验证，全部成功后事务提交默认根与已迁资产根，再逐项核验清理对应源文件；已经在目标的图片不删，不递归删除目录或未知文件。当前默认位置不变时也支持显式收拢旧目录图片。提交前失败保留旧根/原图；提交后清理失败保留原件并返回warnings。相同内容目标可复用，冲突文件不能覆盖。位置更新和迁移均禁止与新增/恢复采集、导入及调度写入并发；已有活跃操作时409。会话不参与设置。
任务条目冻结文章ID。清单coverage.complete只有到达来源末尾才为true，分页上限和受阻不能作完整覆盖。
篇数或批次上限使发现任务进入paused，stopReason分别为article_limit/page_limit；只有到来源末尾才是reached_end。maxArticles为1..10000整数，省略维持旧API；maxPages为1..200整数。每批请求最多10条推送，推送可有子文章，不能固定换算篇数。篇数按本任务实际检查的唯一文章身份计，包括库中已有记录。单批超额的清洗后条目与游标存pendingPage，resume优先消费余项并只扩展已到上限的原始预算，不漏页尾或重复计数。内部maxArticles/articleBudget/inspectedIds/pendingPage不对外输出，不持久化会话。自动下载的新增文章ID随checkpoint持久化，结束或达到预算后与建档任务在同一事务中交接。
文章分页默认page=1、pageSize=50，上限100；SQL执行筛选、COUNT和稳定publishedAt DESC,rowid DESC排序，固定2条摘要查询，不展开正文/逐条资产查询。空页保留total，非法整数或筛选返回400；客户端筛选回第一页、跨页保留选择并忽略较旧请求响应，阅读室需要完整列表时逐页加载。
自动更新由manual启用或用户重新连接后nextCheckAt设为当前时刻，后续仍按intervalMinutes；15分钟会话窗不延长，不自动捕获。封面失败可明确点击重试，保留服务端冷却，不由轮询循环重试或获取正文兜底。
UI重连上下文只有目标公众号存在且原任务归属相符才有效；无效/不匹配参数不能触发连接或继续。显式点击连接后仍由用户返回任务并选择继续，不自动恢复采集。聚焦/滚动只在进入有效目标或首次加载完成时执行，不被列表轮询重新触发。任务实体/状态/API保持不变；completed进入紧凑可展开历史，所有非completed任务仍保持操作可达。
选择总数沿用临时Zustand快照，不持久化选择；全选与半选仅由当前页可选文章派生，已下载/不可访问排除。工具条独立呈现总数与本页/其他页或筛选外数量，不把跨页选择误示为当前页全选。Base UI使用indeterminate:boolean和对应减号/aria mixed，不使用checked字符串。
单行下载复用act同步busyRef防止pending连点重复提交，成功只移除该篇已选快照，其他跨页选择保持；失败保留选择，显示原有安全错误，不自动重试/连接。正文与图片仍由既有任务状态机验证，不能请求成功就标已下载。downloading/unavailable不发单行请求，complete只本地阅读。

## 4. 校验与错误

| 边界 | 处理 |
|---|---|
| 非允许域名/重定向/路径 | 拒绝请求，不能访问内网或任意文件 |
| 非图片、MIME不匹配、截断 | 拒绝提交完整资源 |
| 验证、认证、限流 | 停止共享通道，保存任务断点，不循环重试 |
| 缺图/中断 | 文章partial、任务可解释，保留有效图片供恢复 |
| 导入越界/原件缺失 | 拒绝或返回错误，原件保持只读 |
| 失效会话 | 等待用户连接，不假装定时成功 |
| 无来源封面 | 返回404或占位，文章记录与归档状态保持 |
| 封面下载失败 | 安全错误和短期冷却，不因轮询反复请求，不回退获取正文 |
| 封面缓存失效/损坏 | 校验后重新取得；源变更使用独立缓存键，不能读取任意本地文件 |
| 相对/越界/链接目录、目标冲突或不可写 | 拒绝切换，返回明确安全错误，不删除原图或覆盖目标 |
| 迁移源缺失/指纹不匹配、复制或提交失败 | 保持原根与原图，不减少归档计数 |
| 已有采集/导入、另一迁移进行中 | 返回409 busy，不并行搬动文件 |
| 目录选择取消 | path为null，当前设置和文件不变 |
| 非法分页/篇数/批次、未知状态或日期区间错误 | 400；不启动任务、不修改文库；未知公众号筛选返回空页 |
| 已切换但旧文件无法清理 | 新图片继续可读，warnings说明残留副本，不递归清理 |
| UI定位ID不存在、任务与公众号归属不符 | 保留普通页面，不进行连接/继续，不错误聚焦其他实体 |

## 5. 正常与异常用例

正常：发现清单 -> 选中5篇 -> 建立5个条目 -> 保存有效资源 -> 本地阅读。
基本：仅添加或刷新清单，文章discovered，不自动全部下载。
封面：发现封面 -> 目录可见时缓存 -> 点击放大；文章仍discovered、正文为空、正文图片数为0，不创建采集任务。补齐旧封面复用已连接公众号的发现流程。
目录基本：选择新位置 -> 保存位置；新下载写新根，旧图留旧根、重启后仍可读。目录迁移：勾选同时迁移 -> 保存并迁移图片 -> 校验复制所有登记根 -> 提交位置与资产根 -> 清理迁走的登记源文件。取消选框或路径错误不修改当前保存位置；勾选默认关闭、成功及刷新后关闭。
异常：同文短长链接重复出现应归并；缺图不能complete；空壳/验证页面不能入正文；未知Host/Origin不允许驱动本地服务。

## 7. 错误与正确做法

错误：图片失败仍把文章写成已完整，增量去重永远跳过它。
正确：分别保存正文与资源状态，只有全部预期图片验证成功才complete，恢复时重新验证本地资源。

错误：达到页数上限就显示全部历史，或将连接成功当作历史可访问证明。
正确：公开显示本次覆盖和终止原因，实际分页与正文成功各自验证。

错误：为待采集文章逐篇下载正文取首图，或把封面写进正文assets后显示已归档。
正确：保存清单封面，按需读取独立缓存；只有用户选中采集且正文与全部图片验证通过才计完整。

错误：先删除旧图片再复制，或更改根目录后直接假定旧资源已迁移。
正确：默认只记住新默认根和旧资产根，不搬图片；显式迁移时才在全部复制校验成功后事务提交根设置与资产根，旧URL继续可读。只清理已验证迁走的登记文件，已在目标的图片不能删，失败保留原件或提示残留。

## 筛选控件与旧版迁移入口

范围：UI受控下拉、日期范围与迁移入口细化，HTTP/数据库不变。
签名：SelectControl(value,onValueChange,options,label,disabled?,id?,className?)；DatePicker(value,onValueChange,label,min?,max?)。日期仍映射since/until，空字符串表示不筛选，下拉accountId/status允许空字符串全部。
契约：BaseUI Select/Popover管理焦点、键盘和关闭，date-only计算+上海今天不做UTC错日转换；无效格式/min/max不写入筛选。跨页选择、旧响应隔离保持。迁移仅设置高级可达，复用POST/settings/choose-directory返回path|null，不调用PUT/settings，选定后仍需显式POST/import。
校验：非法/逆向日期显示可恢复反馈，不能发送非法查询；目录取消保留原输入，不支持选择时可手填；选择不自动迁移/不改保存位置，原迁移后端只复制安全校验保持。
正常：选择公众号/状态、选起止日期、清空；设置高级→迁移旧版资料→选择源目录→显式迁移。基本：空值不限制列表。异常：无效日期不能改filters；源不存在或选择失败保留用户路径和原文库。
测试：空/全部、菜单键盘/焦点、日期闰年/月跨界/上海今天、起止禁用与清空、实际过滤与选择不丢失、320/390px浮层；fake目录取消/选定/不支持、手输提交/原件和图片根不变、忙碌和Dialog焦点。
错误：为统一外框但保留原生蓝色展开面，或选择源目录后自动迁移/改变图片根。正确：实际浮层统一主题且可访问；选择只填路径，迁移显式提交且不冒充通用备份恢复。

## 信息披露与操作后果

本轮仅调整展示，既有API、数据库、存储根和任务ID冻结契约不变。

- 设置输入保留可访问名称“正文图片保存位置”。`directory.trim() !== settings.imageDirectory || migrateExisting` 时才显示并关联 `directory-help`；非默认输入才显示“恢复默认”，点击只改草稿。PUT/settings仍显式携带布尔migrateExisting，选择文件夹/恢复默认不保存，迁移失败与清理警告保留。
- 选择总数可见，本页与其他页/筛选外范围通过原生details展开；分页/筛选不改selected，下载确认仍使用冻结的具体文章ID。
- 账号连接过期/受阻、历史覆盖未完整、任务错误/暂停、阅读缺正文/缺图/本地读取失败均不能随次级说明一起隐藏。正常完整阅读页脚只保留原文链接；本地图片失败即使文章原status为complete也显示读取失败提示，不再声称已完整保存。
- 原生details提供键盘展开和状态语义；隐去视觉标签不删除中文可访问名称。无面包屑后仍保留每页h1、导航aria-current、skip焦点与断线重连。
- 回归覆盖条件提示/描述关联、默认恢复仅改草稿、跨页披露、单/多号及过期/受阻、完成任务折叠、正常与失败阅读、手机无溢出。测试不向微信发送请求。

## 桌面导航与图片窗口

内部导航按钮调用既有navigate，不更改业务状态/参数；角色为button，aria-current=page表达当前位置。app-shell默认禁选，作者名、文章标题（含阅读目录）、正文、关于内容和input/textarea显式允许选取；页面标题、统计、日期、状态、设置标签和操作说明不可选。共享Button在鼠标点击且非空选区anchor/focus位于当前按钮内时保留选区并跳过业务onClick；键盘触发和无选区普通点击仍调用原处理。内容按钮拖选不触发导航，输入编辑与键盘操作保持。原图资源仍通过已验证本地assets URL读取，不暴露任意文件路径。图片适配/原图切换只改变Dialog内展示，不触发下载或新窗；关闭/换图重置模式，失败保留可见反馈。

主进程拒绝所有新窗和非主界面路径的顶层导航。外部微信文章与明确的五个致谢仓库通过白名单交shell.openExternal，其余文件/协议/任意站点拒绝，失败需处理。renderer继续sandbox/contextIsolation，无Node、无通用IPC或文件打开接口。URL规则、拒绝矩阵与模拟外部调用验证见docs/desktop.md。

## 阅读修复入口

complete且图片正常无检查/修复操作；图片读取失败显示“本地图片无法读取。”和“修复图片”，partial为“补全内容”，discovered为“下载文章”；downloading/unavailable保留提示且无重复入口。复用model.recheck打开冻结本篇ID的采集确认，打开/取消不发送建任务请求、不清空原目录选择，确认仅提交该篇，忙碌禁用。后端既有采集校验并复用有效文件，按缺失内容补全；无新API或存储变更。隔离回归覆盖六种阅读状态、单ID/取消/忙碌，以及实际拖选和输入复制。

## Windows文件夹选择窗口

既有POST/settings/choose-directory与两个前端入口保持一致，返回path或null，不保存设置或迁移图片。WindowsPowerShell5 STA通过Common Item Dialog的文件夹模式展示资源管理器布局、地址栏和搜索，仅接受文件系统目录；保留当前保存位置作为初始目录，初始位置不存在仍允许重新选择。取消HRESULT转null，其余错误保留可恢复手填提示，单窗口busy与服务退出取消沿用现有调用。脚本使用UTF8 BOM保证PS5读取中文，stdout保持UTF8 JSON；不增加renderer权限或桌面IPC。

## 阅读目录与正文的独立生命周期

正文按routeId独立请求并优先展示；目录进入阅读室或归档摘要计数改变后完整分页刷新，切篇复用目录，不以截断目录提速。两路独立取消与旧响应隔离，目录失败保留已显示正文并提供重试，不冒充空文库。不持久化业务实体。

## 共享通道受阻

节流等待之前和之后均检查共享gate与取消；等待期间其他请求触发限流、验证或认证阻断时，不允许等待者继续fetch。错误语义与已有有限网络重试保持，回归用内存源而非微信请求。

## 完整文库备份与恢复

桌面原生菜单和托盘提供“备份文库…”/“恢复文库…”，与旧版资料迁移分开。备份先检查无活动任务，明确告知本地服务会暂停、微信需重连；只停止自己拥有的sidecar，复用外部服务时拒绝备份且不关闭外部服务。离线Node工具先取得同库锁，再只读打开SQLite并创建一致快照，复制全部登记的完整资产（包括多个图片根）及本地封面缓存；不保存会话票据。

v1备份目录以shiye-backup.json为完成标记（format=shiye-library,version=1），数据库及文件记录相对路径、大小和SHA256，图片按articleId/seq关联；manifest最后写入，失败目标不能当成完整备份。拒绝路径逃逸、目录链接、文件冲突、缺失或损坏资产。备份失败不得删除源库或递归清理用户目录。

写入与恢复共用16 MiB清单上限，按序列化后的UTF-8字节数计量，等于上限可用。超限备份在发布完成清单前失败并保留原库，不返回成功；恢复也拒绝超限清单。该限制针对清单，不是图片总大小或固定文章篇数。

恢复校验manifest、数据库结构与图像关联后只写新的空文库，原备份及现库不覆盖；图片统一登记到新根pictures，账号断开、自动更新关闭、活动任务暂停，不自动连接或下载。完成后显式选择打开新文库；取消打开保留当前文库。备份/恢复工作进程只接收父进程一次明确类型的IPC操作，不增加renderer文件访问或HTTP写文件接口。


备份契约签名：`backupLibrary(sourceRoot, destination, signal?)`、`restoreLibrary(backupDirectory, targetRoot, signal?)`，均返回`{directory, images, articles}`。桌面工作进程仅接收一次`{type:"backup"|"restore", source, target}`，返回`{type:"result", result}`且退出0，或`{type:"error", message}`且退出非0；父进程同时验证结果和退出码。父连接丢失沿取消路径释放锁，不发布成功。

| 输入或事件 | 可观察结果 |
|---|---|
| 两个图片根、中文与空格路径 | 完整复制登记资产，恢复后本地URL可读 |
| 已运行的文库、活动任务 | 拒绝冲突操作，不关闭外部服务 |
| 非空目标、路径链接、逃逸或恶意SQLite结构 | 拒绝，保留源和原有目标文件 |
| 清单/图片/数据库摘要不符或身份关联无效 | 恢复失败，不返回成功 |
| 中断或取消 | 释放源锁，失败目标保留`.shiye-incomplete`；启动入口在建锁/开库前拒绝半成品 |
| 备份工作进程失败 | 不报成功，仍尝试重新打开原文库服务 |
| 恢复完成选择“暂不打开” | 当前文库不切换 |
| 新库打开失败 | 回退原文库，恢复记忆位置 |

最小验收包括：并发gate红绿回归、目录等待时正文先展示、快速切篇及旧响应隔离、八项离线备份恢复边界测试、桌面消息/进程退出与回滚测试、真实随包程序备份→恢复→打开正文/图像。错误做法是只复制当前图片目录、忽略worker退出码或覆盖原库；正确做法是锁住完整源、核验多根副本，仅发布完整的新文库。

## 阅读位置与任务恢复

作用域为本库已存在的文章。`GET /api/reading-positions/:articleId`返回`{body:number,gallery:number}`，未记录时均为0且GET不落库；`PUT`只接受`{mode:"body"|"gallery",top:number}`，合并对应视图后返回同结构。`top`必须有限且在0..10000000，未知字段或类型错误400，文章不存在404。使用SQLite既有runtime单键保存最多200条最近触达记录，无schema变更；不写正文、作者、会话或文章选择。

| 情况 | 结果 |
|---|---|
| 正文后切到图集 | 两种位置独立，互不覆盖 |
| 切篇、返回、刷新或随包服务换端口重启 | 从本库位置恢复，不依赖旧origin的localStorage |
| 图片迟加载、滚动高度暂时不足 | 等内容高度恢复，不能把目标位置提前写为0 |
| 读取位置失败 | 正文仍可读，不用默认0覆盖服务端原记录 |
| 超200条、损坏或恶意偏好 | 保存有界、校验后的数字记录，不恢复实体或可执行内容 |
| 多公众号目录 | 条目内显示对应来源；单来源省略重复名 |
| 任务缺会话或共享通道受阻 | 主操作前往连接微信，连接前不请求resume |
| 重新连接成功 | 返回指定原任务后由用户继续，不自动恢复这条任务；既有用户设置的更新策略另循原契约 |

正常用例为读到中段后换篇再回来、两视图分别恢复；基础用例为首次打开位置0；错误用例为非法top、未知文章、损坏runtime和失败GET。必须验证宽屏分栏/窄屏页面滚动、迟加载、重开、200条上限、本库隔离及连接→明确继续闭环。错误做法是仅存按origin隔离的localStorage或在GET失败后立即写回0；正确做法是本库校验保存、等待恢复完成且保留有效旧记录。

## 审查缺陷的边界回归

### 范围与签名

沿用`validateImage(buffer,suppliedMime?)`、`restoreLibrary(backup,target,signal?)`和现有暂停、阅读位置API，无新增格式版本、数据库DDL或依赖。修复格式结构误判、最终恢复路径冲突、取消终态及阅读错误反馈，不扩大文件/网络权限。

### 契约

- 恢复最终目标路径的登记与实际字节一致；首轮消歧与后续候选均遵守“未使用或同摘要才能复用”。不能因为备用名称存在就跳过不同内容的复制，却登记新的摘要。无法安全消歧时返回错误，保留原库/备份，不发布成功。
- 共享图片验证检查格式必要的数据块/帧、有效尺寸与边界，不能只凭头尾或容器长度。结构校验不保证任意压缩码流都能由每种浏览器解码，不能在文案或报告中夸大保证；浏览器失败仍有明确修复入口。
- 本地`validAsset`等异步校验之后和最终文章/任务提交之前仍检查取消；已确认暂停不能被迟到的完成写入覆盖。
- 文章列表标题和阅读室常规入口明确正文，图集入口明确图集；阅读器目录内切篇、主动切换及刷新保留当前视图。
- 读取位置失败重试读取；保存失败重试当前有效位置，不能重新读取旧值并跳走。提示仅异常时出现，在阅读中段可见；旧文章/旧视图请求不得覆盖当前错误或位置。

### 验证矩阵

| 输入或时序 | 可观察结果 |
|---|---|
| 多根两图同相对名，且名字等于第二图备用名 | 不得误用同一不同内容文件；成功时逐图摘要匹配 |
| 空RIFF/WEBP、无帧GIF、无像素BMP、缺IDAT PNG | 拒绝或不计完整，不能被后续validAsset当成有效归档 |
| 最后一次本地图像校验期间暂停 | 最终paused，保留原件与已完成进度 |
| 图集之后点另一篇标题 | 进入该篇正文，无新采集请求 |
| 保存位置失败后点击重试 | 当前位置保存成功，无旧位置GET或跳转 |
| 读取位置失败后点击重试 | 恢复校验过的位置，保持慢请求与用户滚动保护 |

### 用例、测试与反例

基础用例为有效图像采集与普通备份恢复；正常扩展为同内容复用、多轮消歧、暂停后继续复用有效图片。错误用例必须来自真实临时Store/备份流程或可控异步时序，先证明原缺陷再修复。测试同时检查状态、实际文件摘要、原件未变和请求次数，不能只断言返回成功或按钮文案。错误做法是修改测试期望接纳坏文件或把保存失败改成重读旧位置；正确做法是在共享校验/最终提交入口修复，并用同一复现回归验收。

## 启动状态恢复的查询边界

范围：`new Store(dataDir)`恢复异常退出的本地状态，既有DDL、正文与资产结构不变。文章恢复使用单条`UPDATE articles SET data=json_set(...) WHERE json_extract(data,'$.status')='downloading'`，只将命中的status改为partial、error改为“采集中断，可继续补全”。SQL仍需检查记录状态，不能据此声称启动耗时与文库大小无关。

运行/排队任务仍暂停，running条目回pending；已连接账号断开，不启动微信请求。已完成及其他非downloading文章的原始JSON保持逐字节不变，资产表不变，不为检查文章状态调用`articles()`展开所有正文和资产。

基本用例为空库启动；正常用例为千篇已完成文章夹杂中断文章；异常退出用例同时有running/queued任务和连接中账号。`test/store-startup.test.ts`检查恢复值、非目标原始JSON、资产、已完成任务不变，以及空库/千篇完成文章的SQL prepare次数相同、无资产查询。错误做法是先读取并装配全库再逐篇检查状态；正确做法是在数据库内筛选和更新目标记录。

## 多图资源边界、操作进度与连续预览

### 1. 范围

所有整篇图片校验（含旧资料导入）顺序检查；已配置图片根的ImageStorage初始化不读资产表。仅缺根时查询旧library路径或是否有记录，不将全表JSON传回应用。保留原目录推断、图片校验、暂停和不完整状态定义，无schema或依赖变更。

### 2. 签名

整篇本地校验使用`ArchiveService.validAssets(assets: StoredAsset[], signal?: AbortSignal): Promise<boolean>`，下载与旧资料导入共用。遇到无效图片返回false；取消沿signal抛出，不返回完整。`ImageStorage`构造签名不变。

备份/恢复前三参兼容，新增可选第四参`onProgress({phase,completed,total})`。phase限定`checking|database|images|covers|publishing`；0/0表示不定进度，其余为当前阶段处理项计数。checking包括文件摘要及逐图结构/身份检查，可对同文件检查多遍，不是唯一文件总数；复制/发布按实际文件数。worker新增单向`{type:'progress',progress}`；既有result/error及退出码成功条件保持。

### 3. 契约

进度不含路径、文件名、会话，不新增renderer权限。桌面从开始即显示暂态标题/任务栏，发布前最多0.99，重开服务时仍显示进行状态；成功/错误提示前及finally恢复标题拾页、移除任务栏进度。阶段计数不是整库百分比、唯一文件总数、字节进度或预计时间。

本地放大Dialog只遍历当前文章完整资产，上一张/下一张文字按钮和左右键不循环，首尾禁用；单图省略翻页控件。换图重置原图模式；原图横向溢出时方向键用于滚动，Escape与关闭焦点返回保持，不新开资源窗口。

### 4. 校验与错误矩阵

| 场景 | 可观察结果 |
|---|---|
| 200张有效本地图 | 校验最大在途1，仍验证全部预期图片，无来源请求 |
| 校验期间暂停/本地图失败 | await后检查取消，不能提交complete；失败不计完整 |
| 记忆根/无根旧library/空库 | 分别不扫描资产、识别旧根、保存默认根 |
| 无效phase/字段/整数范围或worker终止后进度 | 忽略，不改变窗口与结果，不复活进度 |
| 选择取消、worker失败、服务重开失败 | 清除反馈，保留现有安全失败/源保护行为 |
| 放大首尾、单图、原图横向滚动 | 边界不越界，无无用控件，方向键不抢滚动 |

### 5. 用例

基本：无监听备份调用、普通单图预览、空库启动。正常：双根多图备份恢复有阶段进度，同窗连续看完整图片。异常：暂停恰逢最后校验、坏图、坏IPC、失败或迟到消息，预览图片读取失败。

### 6. 测试

资源回归覆盖下载/跳过已完成/旧导入复用与末尾检查、有界峰值、暂停与目录兼容；备份与桌面回归断言实际阶段计数、忽略矩阵、终态清除和结果/退出码。浏览器桌面/窄屏检查连续翻图、单图/首尾、键盘/焦点、模式重置及原图横向滚动；真实portable菜单双根备份恢复后核对原表/逐图hash不变。

### 7. 错误与正确

错误：下载改顺序但导入仍Promise.all；或用复制完100%冒充备份已发布。正确：共享有界检查覆盖所有入口，保留最终校验和取消；进度描述实际阶段，结果和退出码共同决定成功。错误：左右键无条件翻图覆盖原图滚动；正确：根据预览模式及溢出保留实际滚动行为。

## 单文件读取前保护与任务历史

### 1. 范围

本地图片被外部替换后，下载复用、导入复用及末尾检查不能先整文件读入，再判断是否超限。

### 2. 签名

`ArchiveService.validAsset(asset: StoredAsset): Promise<boolean>`委托`ImageStorage.validAsset`，复用存储层`readImage(path, expected?)`。迁移仍使用同一个读取校验入口，无新增API或schema。

### 3. 契约

本地图片有效性检查在整文件读取前拒绝非法登记大小、超过32 MiB或实际大小与登记不一致的文件；路径/普通文件/链接边界和读后的结构、长度、摘要校验保留，失败返回无效，不覆盖源文件。该保护与整篇顺序校验共同限制资源使用；不宣称消除文件外部并发修改的所有竞态。测试需证明拒绝发生在整文件读取前，而不是读入后返回false；有效图、大小不符、超限、缺失、链接及读后损坏均覆盖。

### 4. 校验与错误

登记bytes必须为1..33554432的安全整数，实际文件大小必须相等；32 MiB本身允许。文件缺失、链接、越界、结构/摘要不符均返回false；不删除或覆盖原件。迁移的已有抛错和回滚保护保持。

### 5. 用例

基本为有效图；正常为边界32 MiB有效图；异常为超限替换、同大小坏图、非法登记或丢失文件。

### 6. 测试

`test/image-read-bound.test.ts`跟踪目标readFile调用，断言超限/大小不符/非法登记时调用数为0，有效边界仍执行结构及摘要校验。关联整篇有界、迁移和导入回归保持。
