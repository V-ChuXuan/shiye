# 隔离可靠性演练

## 1. 范围
验证大目录分页、完整文库备份恢复、受控慢操作取消和自有工作进程中断后的保护。不操作用户文库或微信，不证明真实断电、真实慢磁盘或任意文库容量。

## 2. 入口与输出
先`npm run build`，再`node scripts/reliability-drill.mjs`。输出在`data/maintenance-reliability-verification/reliability-result.json`及独立临时文库中，记录样本、分阶段耗时、RSS、进程中断点、文件观察和证据限制。无新增HTTP、数据库schema或系统配置。

## 3. 契约
样本为10000篇短文本、10000条完成任务、8张合计544字节验证图片；小图不代表大附件吞吐。逐页API读出完整目录，备份到新目录，再恢复新空目录并验证离线读取。源数据库表与图片、原备份摘要保持。

受控延时及IPC屏障用于在安全检查点取消或终止本脚本创建的子进程。备份进程中断保留源文库锁与目标未完成标记；恢复进程中断只要求新目标标记，不制造源锁。受保护目标拒绝重入，在另一个新空目录从完整备份恢复。不自动删除遗留锁或未完成目录。

临时文件调查最多三类各三轮，观察Store写入关闭、SQLite备份快照、完整恢复的文件事件。fs.watch不提供创建者PID，捕获文件名不能断言由SQLite、防护软件或其他进程创建；无现成进程跟踪工具时如实停止，不安装或修改防护/驱动/日志模式。

## 4. 校验与错误
| 条件 | 结果 |
|---|---|
| 源表/图片或备份摘要改变 | 断言失败，不报告通过 |
| 中断目标缺少未完成标记/被覆盖 | 断言失败 |
| 遗留锁或未完成目标 | 拒绝重入，保留保护文件 |
| 自有子进程超时 | 有界停止本脚本持有的进程，不影响用户服务 |
| 临时文件观察出现错误 | 保留事件与错误，不忽略未知文件安全失败 |

## 5. 用例
正常：100页目录、完整备份恢复并离线读图。异常：备份和恢复在images/publishing各中断一次；两类操作在图片检查点受控等待后取消。调查：Store写入关闭、备份快照、完整恢复各三轮。

## 6. 验收证据
2026-10-25本机Node24.12初次演练通过；100页API约5.26秒，备份约0.65秒、恢复约1.28秒，仅是该短文本小图片样本，不是性能承诺。报告RSS包含建库、全表摘要断言与演练工具累计内存，不能当作应用稳态或单阶段内存。四个进程中断点与两个慢操作取消的原件、标记和保护均通过。

九轮观察实际捕获`ARCHIVE.SQLITE-SHM.tmp`，单纯Store写入关闭也出现，说明不依赖备份发布路径；创建进程仍无归因证据。现有安全中止规则保持，未宣称偶发问题消除。

## 7. 错误与正确
错误：通过一次演练就承诺断电安全或归因未知进程；正确：保存样本、注入点和事件，明确验证边界。错误：为了通过演练删除锁或忽略陌生文件；正确：保留保护，选择新空目录验证恢复。
