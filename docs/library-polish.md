# 阅读检索、任务查询与界面恢复

## 1. 范围
0.1.1补齐阅读查找和状态指引，减少内部历史任务解码，增加界面异常恢复。沿用文库、HTTP结构和视觉，无新增依赖、schema或renderer权限。

## 2. 签名
- Store.hasActiveJobs(accountId?, kind?)返回活动任务是否存在；nextQueuedJob()返回最早queued任务或undefined。
- 阅读使用独立会话内标题和来源ID状态，Input/SelectControl沿用，无新接口或持久化key。
- 主进程处理当前webContents的render-process-gone/unresponsive/responsive，同窗受控重载。
- package/lock、`GET /api/about`与随包metadata版本一致为0.1.1。

## 3. 契约
标题trim后不分大小写字面包含，来源ID精确匹配，AND组合。阅读室及宽屏目录共享筛选，来源取完整文库，单来源省略来源控件。筛选不改变正文、视图或位置，也不影响文章目录选择/筛选；无匹配仍可清空，原本空库沿用空库状态。发现弹窗取当前model账号连接状态，已连接省略前置说明。

从阅读室卡片打开正文时记住阅读室返回路径，切篇不覆盖该路径；返回后保留本次阅读筛选，重新加载应用后清空检索。

活动状态仅queued/running；SQL EXISTS返回存在性，下一queued按rowid ASC、LIMIT1保持FIFO；启动仅解码待恢复状态，其他历史JSON不变。旧jobs数组与open/history接口保持。

renderer异常只处理当前主窗，明确重载才恢复受控本地页面，无响应可等待，自行恢复后旧响应不强杀健康页面。重载不改变后台PID/任务/会话/锁；服务同时停止则交给原生服务恢复。维护/退出/重复和迟到事件互斥，失败等待下一次明确选择。

桌面服务退出时，不应被尚未发出完整请求头的HTTP连接无限阻塞。只关闭自有服务中没有正在处理请求的连接；已开始的处理保持完成与文库锁释放顺序，不通过强杀或删除锁冒充正常退出。

备份与恢复的发布总数为暂存目录估计；仅在全部文件发布、暂存目录成功移除后，才按实际发布数校准最后一条进度。此时未完成标记仍存在，回调取消须保留标记；陌生残留文件仍阻止发布完成。

## 4. 校验与错误
| 条件 | 结果 |
|---|---|
| 正则符号/大小写/空白 | 按字面匹配，trim后空为无标题限制 |
| AND无匹配或来源失效 | 保留控件及清空，正文不消失 |
| 筛掉当前正文 | 正文/模式/位置不变，不自动切篇 |
| 文库加载或失败 | 既有独立状态/重试，不伪称空库 |
| 无queued/多号/非活动历史 | 无下一项/按scope判断，FIFO不变 |
| renderer异常/重载失败 | 等待明确选择，后台和原件保持 |
| 主动forceCrash/重复/旧响应 | 不重复提示，不作用于新窗口或文库 |
| 与维护/服务退出交叉 | 保持互斥，服务死亡仍进入既有恢复 |
| 退出时存在未完成请求头/空闲连接 | 不阻塞正常退出，已开始请求不被误杀 |
| 暂存临时文件消失/存在陌生残留文件 | 成功后校准实际发布数/保留未完成标记并失败 |

## 5. 用例
基本为单号与健康界面；正常为多号检索、筛掉正在看的文章及明确重载崩溃界面；异常为无匹配、加载失败、自行恢复、重载失败和界面/服务同时停止。

## 6. 验收
隔离浏览器覆盖组合、清空、单来源、无匹配、共享状态、正文/模式/位置/选择保持、动态连接、键盘与窄屏。大量完成任务测试观察限定查询和解码，不以耗时冒充容量。VM覆盖选择/失败/互斥/迟到时序；最终portable仅对隔离主窗注入renderer崩溃，核单窗/相同后台PID/任务/锁/页面。版本核对lock/API/app与包。

原始HTTP连接测试覆盖首次及后续不完整请求头、未收完的正文、同连接两个活动请求；退出必须code0且释放锁，活动请求正常完成。发布进度测试覆盖临时文件消失、陌生文件保留和最终回调取消。

## 7. 错误与正确
错误：阅读检索复用采集筛选；正确：独立会话状态，只改变阅读列表。错误：取下一项先读全部历史；正确：SQL按原顺序取所需任务。错误：renderer崩溃重启服务并继续采集；正确：明确重载窗口，保持后台与采集规则。

平台依据：[Electron webContents](https://www.electronjs.org/docs/latest/api/web-contents#contentsforcefullycrashrenderer)。互斥与URL边界仍遵守[桌面契约](desktop.md)。
