# Ponytail UI 检查与处理

审查日期：2026-10-24。范围为个人本地单用户归档应用的前端、依赖、构建和浏览器验收路径；不对真实微信接口或长期定时可用性作结论。

## 先修真实问题

| 发现 | 原因 | 处理 |
|---|---|---|
| 跳主内容误切页 | #main-content与hash路由共用 | 阻止锚点导航，仅聚焦可聚焦main；键盘回归保留原路由 |
| 时间少8小时 | UTC ISO直接裁剪 | ISO时刻按Asia/Shanghai格式化；已规范文章日期保留原值 |
| 小字低对比 | 8–9px英文装饰及重复色值覆盖 | 删除装饰小字，统一语义前景token与12–16px操作/阅读文字 |
| 轮询覆盖操作结果 | 旧请求后返回 | 按请求序号接纳最新结果 |
| 跨页筛选丢失 | 无账号参数的路由覆盖store | 只有显式路由参数才改筛选；显式“全部”仍可重置 |
| 偏好保存阻塞选择 | storage拒写异常穿透事件 | 容错读写；选择和阅读继续正常 |

## 减少重复维护

- 原App同时包含四页、所有弹窗和请求状态；现在按业务拆分，App只协调页面。App约44KB变为约4KB，不能把职责拆分宣称为整个项目净减90%的代码。
- 原18种手绘图标替换为Lucide具名导入；按钮/输入/弹窗等使用12个实际需要的官方Base Nova源码组件。
- 旧约34KB样式级联被约22KB语义token与布局样式替代，另保留必需官方Nova方向/状态CSS子集。删除未使用的Tooltip、Sheet和Separator生成文件。
- 不预装拖拽、查询、路由、重型表格、第二UI或动画库。UI基础依赖版本固定；`npm run check:ui-deps`检查职责唯一和基础包去重。
- 组件迁移增加了成熟行为库的体积。首次整体入口约583KB；按需加载阅读器/弹窗并使用LazyMotion后，入口约409KB（gzip约137KB），其余阅读/弹窗分块按需加载。它仍大于迁移前约261KB入口，这是成熟组件和交互能力的成本，不作“比旧版更小”的承诺。

## 验收重点

迁移前先跑原33项测试和现有浏览器烟测；新回归在旧构建上复现skip路由错误，再用于迁移后验证。新增纯状态/时间测试，以及真实勾选→确认→冻结ID、跨号部分失败重试、只补缺图、分栏键盘宽度变化/偏好恢复、Escape焦点恢复、减少动画偏好与移动单栏。

截图还暴露Nova Tabs缺少官方orientation变体的问题：图库没有页面溢出却被横向挤窄。已补官方必要variants，并要求390px图库宽度及图片实际尺寸达标，避免只凭“不溢出”判定通过。

没有以截图或DOM存在冒充微信实际采集成功。本轮测试源为隔离本地MockCollector；用户已有归档保持不变。

本轮按个人本机单用户负载检查App布局、轮询调用、Store聚合及现有图文/迁移测试。保留现有组件和数据结构，未新增依赖。

| 真实问题 | 复现与最小处理 | 验证 |
|---|---|---|
| 关于/设置外层居中，内层另限宽并靠左 | 修复前1440px设置左间距32px、右288px。把宽度约束移到共用外层，删除两个内层max-width | 900/1100/1440/2048/2560px几何比较标题与面板，320/390px等待真实内容后查溢出 |
| 每4秒统计与公众号轮询逐篇读取正文和资产 | 467篇、2个公众号的隔离回归中summary准备SQL2808次，accounts1871次；直接按表与公众号聚合，避免为计数组装实体 | 分别降至2次与3次；完整图片按assets状态计数，partial文章的已存图仍计入，空库返回0，活跃任务/会话阻断语义保留 |

没有增加缓存、后台线程、通用仓储封装或新依赖。SQL调用数下降不表示数据库完全不扫描记录，也不代表全部接口已变为常量成本。文章目录仍使用既有实体读取流程，本轮未做分页/批量加载改造；若文库增长到明显影响目录浏览，再按实测调整。审查没有覆盖逐行全仓库安全审计、真实微信会话或长期定时运行。
