# 使用指南

首次使用步骤和下载入口见 [README](../README.md)。当前界面为中文；本页补充日常操作与源码开发说明。

## 发现与下载

发现默认最多 100 篇、20 批，达到任一上限即暂停。每批最多 10 条推送，一条推送可能有多篇文章；批次不等于文章数。继续任务会扩展预算，重新发起发现则检查最新清单。

文章目录每页 50 篇，翻页和筛选保留选择。全选只作用于当前页可采集文章；行内下载只处理该篇。文章标题和 **阅读全文** 打开正文，**查看图集** 打开本地图片。正文与图集分别保存最近 200 篇的阅读位置，阅读目录有独立的标题和公众号筛选。

默认手动更新。定时发现或发现并下载只在应用运行、内存会话有效时执行，会话有效窗为 15 分钟。验证、限流或会话过期会停止共享采集通道并保留进度；处理微信提示、重新连接后，再明确继续任务。部分归档提供修复或补全入口，文库锁错误由原生提示引导，不自动删除锁。

封面和头像是独立缓存，查看封面不会归档正文。旧清单缺少封面资料时，可连接微信并重新发现清单；头像刷新只读取一篇已知文章的公众号资料，不下载其正文图片。

## 图片与文库

打包版默认在当前用户的应用数据目录创建文库，数据库、文章记录和封面缓存位于 `data/`，默认正文图片位于 `pictures/`。桌面服务仅使用本地回环端口，无需部署服务器。

在 **设置** 更改图片目录，默认只影响新下载和导入，旧图片按登记位置继续读取。勾选 **同时迁移已有图片** 后，先复制校验、更新登记，再清理登记原件，不覆盖陌生文件。公众号或文章改名不会自动搬动图片目录。

通过托盘或 Alt 应用菜单备份与恢复完整文库。先暂停活动任务，保留整个备份文件夹；只移动图片不会带走文章索引、任务和封面缓存。恢复写入新的空文库，不替换当前文库。备份清单上限为 16 MiB，与图片总大小无关。

**取消文库操作** 在安全检查点生效，保留原件和未完成标记。关闭窗口会隐藏到托盘；选择 **退出拾页** 才会停止应用自己的服务，复用的外部同库服务不会随桌面退出而停止。详见[桌面行为](desktop.md)和[取消与恢复](safe-cancel-reader.md)。

在 **设置 → 高级 → 迁移旧版资料** 可复制旧归档，默认最多导入 20 篇。选择目录只填入路径，开始迁移后才校验复制，原件不会被移动、覆盖或删除。详见[数据与接口契约](contracts.md)。

## 已知限制

微信清单使用非公开接口，不能保证任意公众号完整历史或长期无人值守。文章、图片和其他下载内容保留各自权利，不由软件的 MIT 许可授予转载权。

偶发 SQLite 临时文件变化可能让备份或恢复安全中止，创建进程尚未归因。受控容量与中断演练不能证明真实断电安全、大图吞吐或长期微信兼容性，具体范围见[可靠性演练](reliability-drills.md)。

## 源码开发

需要 Windows x64 和 Node.js 24 LTS。后端采用 TypeScript、Fastify 和 SQLite，前端使用 React/Vite。Electron 承载界面，随包的独立 Node 进程管理 SQLite。

```sh
npm ci
npm run desktop:package
```

程序生成在 `release/<version>/拾页-win32-x64/拾页.exe`。桌面开发运行 `npm run desktop`，详情见[桌面开发](desktop.md)。

源码浏览器开发时，在两个终端分别运行 `npm run dev` 和 `npm run dev:client`。也可在构建后运行生产服务：

```sh
npm run build
npm start
```

打开 `http://127.0.0.1:4387`。Windows 双击 `启动拾页.bat` 时，优先通过 `release/启动拾页.cmd` 打开最近打包的桌面程序，兼容旧便携目录；没有桌面程序时才启动源码浏览器模式。启动失败会保留提示，按键后关闭窗口。

| 变量 | 范围 | 默认值或用途 |
|---|---|---|
| `PORT` | 源码服务 | `4387`，不会结束占用端口的其他程序 |
| `WECHAT_ARCHIVE_DATA` | 源码服务 | `data/`；设置后默认图片在该目录的 `pictures/` 下 |
| `WECHAT_ARCHIVE_BROWSER` | 浏览器测试 | 可选的 Chromium 路径，否则寻找已安装的浏览器 |

桌面参数 `--library-root` 和 `--user-data-dir` 用于选择已有文库或独立配置目录。`SHIYE_LIBRARY_ROOT` 是内部子进程连接信息，不是用户配置项。

```sh
npm run typecheck
npm test
npm run check:ui-deps
npm run build
npm run test:browser
npm run test:ui
```

浏览器检查使用隔离 mock 数据，需要已安装的 Chromium，不请求微信。按改动另有 `npm run test:covers`、`npm run test:settings` 和 `npm run test:reading-details`；`npm run test:desktop` 使用已打包程序和隔离文库。
