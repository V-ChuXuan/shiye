# 退出、取消与阅读操作

## 1. 范围
公众号识别关闭取消、原生备份恢复取消、完整纯文本入口、正文失败重试、窗口状态记忆。沿用0.1.1文库和权限，无新增依赖、schema或通用renderer IPC。

## 2. 签名与入口
- `POST /api/accounts`仍接受现有文章链接或biz/name；来源请求纳入服务关闭生命周期。
- 备份/恢复仍经主进程原生菜单及专用Node工作进程；取消是专用工作进程控制消息，不开放HTTP或renderer文件操作。
- 阅读单篇重试只重新读取当前文章，沿用现有文章GET接口。
- 窗口偏好独立于严格文库绑定记录，保存正常边界与最大化状态。
- 专用worker接受`{ type: 'cancel' }`，安全取消回传`{ type: 'cancelled' }`；原有progress/result/error保持。主进程以最终result和exit为准。
- `readWindowState(file, workAreas)`返回可见边界、有效最小尺寸和maximized；`saveWindowState(file, bounds, maximized)`写独立userData/window.json，结构为`{ bounds: { x, y, width, height }, maximized }`。
- 阅读模型`reloadReader()`仅递增单篇请求修订，保留原文库修订与路由。

## 3. 契约
关闭先取消可中断的来源识别，等待清理后释放文库锁；迟到来源不能在关闭后新增公众号或文章。不得通过延长强杀时间、提前释放锁或中断原子文件写入冒充正常退出。

文库取消只针对当前自有活动工作进程，重复和迟到请求无副作用。主进程等待工作进程最终结果及退出；已完成发布的成功不能被迟到取消改成失败。取消保留原件与未完成标记，不递归清理用户目录。普通取消后恢复原文库使用；取消并退出须在维护收束后退出，不能再启动后台。外部服务始终无退出权。正在进行的I/O只能在下个安全检查点响应取消。

维护期间当前自有服务意外停止，维护取消、失败或保留原库后必须补交既有原生服务恢复；明确选择后才重开。维护完成后只检查仍为当前库的自有服务，不处理已切走的旧服务或外部复用服务。退出确认尚未回答时不叠加提示，继续等待后补恢复、明确退出则退出；与renderer恢复共用原互斥边界。

完整文章有图时查看图集，无图时阅读全文；其余状态的下载、补全及禁用规则不变。正文读取失败显示明确重试，不自动循环；保持文章ID、返回路径、模式、选择及独立阅读筛选，单篇重试不重取文库。旧响应不能覆盖新文章。

零图文章不显示图片计数；保留图集页签兼容跨篇视图偏好，空图集只对完整且零图的归档显示“这篇文章没有图片”。尚未采集或不完整时的零可能意味着图片数未知，仍保持尚未保存表述。

正常窗口边界与最大化分开保存。仅接受有效有限数值；显示器变化、离屏、损坏或不可写偏好不阻止文库启动。恢复时限制到当前可见工作区域，小屏有效最小尺寸不超过工作区域；不更改文库绑定、阅读布局和renderer权限。

## 4. 校验与错误
| 场景 | 结果 |
|---|---|
| 识别中退出、来源迟到 | 取消并等待收束，关闭后不新增记录，锁正常释放 |
| 重复取消、取消后结果到达 | 当前worker一次处理，成功结果优先，等待退出 |
| 取消备份/恢复 | 原件保留，未完成目标保留标记，当前库仍可使用 |
| 维护中取消并退出 | 安全收束后退出，不重开sidecar |
| 维护中自有服务停止后保留原库 | 维护收束后补原生恢复，等待明确选择 |
| 维护完成与退出确认交叉 | 不叠加提示，继续等待后恢复或按选择退出 |
| 零图完整文章 | 阅读全文，不进入空图集 |
| 零图文章主动进入图集 | 无图片计数，显示确实无图片文案 |
| 正文GET失败/重试后切篇 | 原地重试/迟到结果忽略，不重载整个文库 |
| 窗口偏好坏数据、离屏、小屏 | 默认或可见区域回退，不影响文库绑定 |

## 5. 基本、正常与异常
基本：普通阅读、有图入口、健康启动。正常：取消长备份后继续使用、正文明确重试、重启保留窗口。异常：来源不响应后关闭、发布与取消交叉、来源迟到、错误窗口偏好和移除显示器。

## 6. 验收
针对性回归先复现再修复；真实HTTP/sidecar识别退出必须code0、无kill且锁释放。文库worker覆盖取消前后发布、最终回调取消、重复/迟到消息和原文件摘要；便携包验证原生菜单及退出。浏览器覆盖纯文本/图文/其他状态、503单篇重试、迟到响应、上下文保持。窗口单元及实际包覆盖正常、最大化、坏偏好和离屏；最终执行项目全套检查与包源匹配。

维护期间停止自有后台后取消恢复，须出现原生恢复提示；新库切换成功、退出及外部服务不得误提示。容量、慢操作与进程中断演练只在隔离文库执行，分别记录样本、耗时、内存、注入点、摘要、未完成标记与锁保护，不能外推真实断电或任意规模保证。

## 7. 错误与正确
错误：取消即强杀worker或删除锁；正确：取消信号、等待最终结果、安全释放。错误：保存最大化后的bounds当正常窗口；正确：正常边界与最大化分开。错误：重试刷新整个文库；正确：仅重读当前文章并隔离旧响应。
